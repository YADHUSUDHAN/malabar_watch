# Feature Spec: Resilient Dual-LLM Bilingual Reasoning & Advisory Gateway

- **Spec ID**: `SPEC-003`
- **Status**: Approved
- **Owner**: Malabar Watch Engineering
- **Target Release**: `v0.1.0`
- **Dependencies**: `SPEC-002` (Risk Engine), `Pydantic Settings`, `google-genai`, `groq`

---

## 1. Overview & Business Intent

While numerical risk evaluation must be strictly deterministic, **warning communications must be empathetic, plain-language, and culturally accessible**. Generic scientific rainfall readings (e.g. *"180 mm cumulative precipitation with 0.85 decay"*) fail to communicate urgency to grassroots communities in Kerala’s Western Ghats.

The **Resilient Dual-LLM Gateway** takes the verified `RiskAssessment` from `SPEC-002`, reasons over rainfall intensity, antecedent soil saturation, and regional historical precedents, and generates structured, bilingual (English + Malayalam) public advisories.

To prevent early-warning downtime during cloud outages or API quotas, the gateway implements a **zero-downtime multi-provider failover chain**:
1. **Primary**: **Google Gemini API** (`gemini-2.5-flash`)
2. **Failover**: **Groq API** (`llama-3.3-70b-versatile`)
3. **Safety Fallback**: **Deterministic Rule-Based Template Engine** (Zero failure mode if all APIs or network connections are down)

## 3. Data Contracts & Output Schema

### 3.1 LLM Output Data Contract (`BilingualAdvisory`)

```python
class BilingualAdvisory(BaseModel):
    """Structured bilingual early-warning advisory generated by the LLM layer."""

    district_id: str
    risk_level: RiskLevel
    summary_en: str = Field(
        description="2-sentence clear overview of current rainfall and risk in English"
    )
    summary_ml: str = Field(
        description="2-sentence clear overview of current rainfall and risk in Malayalam"
    )
    advisory_en: str = Field(description="Actionable safety guidance for residents in English")
    advisory_ml: str = Field(description="Actionable safety guidance for residents in Malayalam")
    provider_used: str = Field(
        description="Provider fulfilling the request: 'gemini', 'groq', or 'template'"
    )
    latency_ms: int = Field(description="Round-trip latency in milliseconds")
```

### 3.2 System Prompt & Safety Guidelines

```text
You are Malabar Watch, an AI early warning system for extreme rainfall and landslide risks in Kerala, India.
Your role is to summarize deterministic risk metrics into empathetic, clear, actionable advisories in BOTH English and Malayalam.

CRITICAL SAFETY INSTRUCTIONS:
1. Return ONLY valid, minified JSON matching the exact schema below. Do not include markdown code blocks or commentary.
2. Tone: Calm, authoritative, cautionary, empathetic.
3. NEVER contradict the provided Risk Level (e.g. if Risk Level is ORANGE / HIGH, do not state "Everything is safe").
4. In Malayalam, use authentic regional disaster alert terminology:
   - Risk Levels: 'ഹരിതം' (Low), 'മഞ്ഞ ജാഗ്രത' (Moderate), 'ഓറഞ്ച് അലർട്ട്' (High), 'റെഡ് അലർട്ട്' (Severe)
   - Hazards: 'മണ്ണിടിച്ചിൽ സാധ്യത' (Landslide risk), 'ഉരുൾപൊട്ടൽ സാധ്യത' (Debris flow risk), 'മലവെള്ളപ്പാച്ചിൽ' (Flash flood)
   - Directives: 'നദിക്കരയിലുള്ളവർ ജാഗ്രത പാലിക്കുക', 'സുരക്ഷിത സ്ഥാനങ്ങളിലേക്ക് മാറുക'
5. If historical precedent is provided, succinctly reference it to ground the urgency of the warning.
```

## 4. User Stories & Acceptance Criteria

- **US-1 (Bilingual Generation)**: As a resident of Kerala, I want advisories written in natural, fluent Malayalam alongside English so that language is never a barrier to life-saving instructions.
- **US-2 (Zero Downtime)**: As an emergency dispatcher, I need the system to automatically switch to Groq or local templates if Gemini hits rate limits or network issues so that alerts are never dropped.
- **US-3 (Hallucination Prevention)**: As a safety auditor, I need guarantees that the LLM will never alter the mathematically computed risk level.

### Detailed Acceptance Criteria
- [ ] **AC-1 (Gemini Provider)**: Implement `GeminiProvider` using Google GenAI SDK or HTTP client with `response_mime_type="application/json"` and 10s timeout.
- [ ] **AC-2 (Groq Provider)**: Implement `GroqProvider` using Groq SDK or OpenAI-compatible endpoint running `llama-3.3-70b-versatile` with `response_format={"type": "json_object"}`.
- [ ] **AC-3 (Dual Gateway Orchestrator)**: Implement `DualLLMGateway` coordinating the primary-to-fallback cascade with latency tracking.
- [ ] **AC-4 (Template Fallback)**: Implement deterministic, parameterized offline bilingual templates as a safety net when API keys are unset or network is offline.
- [ ] **AC-5 (Malayalam Quality Benchmarks)**: Create automated eval suite in `tests/evals/` verifying Malayalam disaster keywords, character sets, and JSON validation.
- [ ] **AC-6 (CLI Verification)**: Add `malabar-watch --test-llm` command to test live bilingual synthesis and failover from the terminal.

## 6. Edge Cases & Resilience Strategies

| Failure Mode / Edge Case | Impact | Mitigation Strategy |
| :--- | :--- | :--- |
| **Gemini Rate Limit (429)** | Primary provider rejects request. | Catch `429` immediately; failover to Groq without waiting. |
| **Gemini Timeout (>10s)** | Ingestion worker stalled. | Hard 10s timeout triggers Groq fallback. |
| **Markdown Fenced JSON Output** | Parsing error (`json.loads` fails on ````json ... ````). | Pre-processing sanitizer strips markdown code blocks before Pydantic validation. |
| **Both APIs Down / No Keys** | Total cloud outage or offline development. | Fallback to deterministic template generator; log warning. Zero crash. |
| **Malayalam Encoding Issues** | Garbled characters on Windows terminals. | Enforce explicit UTF-8 string encoding across all models and JSON dumps. |

## 7. Verification & Test Criteria

### 7.1 Automated Tests
- **Unit Tests (`tests/unit/test_llm_gateway.py`)**:
  - Test prompt construction from `RiskAssessment`.
  - Test payload sanitization and JSON parsing.
  - Test failover from Gemini to Groq when Gemini returns 500 or 429.
  - Test template fallback when both providers fail.
- **LLM Evals (`tests/evals/test_llm_evals.py`)**:
  - Validate Malayalam keyword presence (`മണ്ണിടിച്ചിൽ`, `ജാഗ്രത`, `അലർട്ട്`).
